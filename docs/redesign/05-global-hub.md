# 05 · 全局中枢改版（工作区维度内收）

> 触发：Console 版落地后确认「中枢的内容在工作区之上，入口和数据却挂在工作区里」。  
> 结论：**中枢升级为顶层场所，工作区成为它内部的一个维度。**  
> 对应实现：`docs/implementation/02-global-hub-brief.md`、Host `hub.overview`。

## 1. 新信息架构

```
侧边栏（全局）
  ├─ 中枢  ← sidebar.panellist，常驻入口（与日程等平级）
  └─ 工作区 / 会话 …

中枢（main 面板，key = workspace-hub，全局唯一）
  ├─ 所有工作区（首页，默认）
  │   ├─ 全局状态条：工作区 N · 进行中 X · 待办 Y · 阻塞 Z · 环境 ready/total
  │   ├─ 需要你处理（跨区聚合，最多 6 条；行带工作区徽标）
  │   ├─ 正在运行（跨区聚合）
  │   └─ 工作区卡片（2 列：任务计数 / 会话 / 环境 / 更新时间）→ 点击进入
  └─ 工作区视图（drill-in）
      ├─ 面包屑「所有工作区 / 名称」+ 切换器（首项：所有工作区）
      └─ 现有 Console：概览 / 任务 / 对话 + ⚙ 设置（仅此层出现）
```

- 标题栏「中枢」按钮保留为**快捷方式**：打开中枢并定位到当前会话所属工作区（不是"打开那个工作区的面板"）。
- 服务器胶囊：打开中枢 → 选中工作区 → 环境 popover。
- 每个工作区不再注册独立面板；面板状态（选中工作区、工作区视图的筛选/滚动）全局持久化；All 视图无筛选，不单独持久化。

## 2. 数据与刷新

| 视图 | Host 调用 | 说明 |
|---|---|---|
| 所有工作区 | `hub.overview` | 一次返回全部工作区的 board（用于注意力派生）、会话计数/行、服务器 cheap summary、totals；4s 轮询 |
| 单个工作区 | `hub.snapshot` | 现有聚合快照（含真实服务器探测）；只在该视图轮询 |
| 设置 | `hub.workspace` | 用选中工作区 + 当前会话（仅当会话属于该工作区） |

- 服务器在 All 视图不做健康探测（只显示本中枢启动的进程状态），避免 N 个工作区 × 健康检查。
- 任务仍按工作区物理存储；中枢不引入全局单板，不改变并发/租约/CAS 语义。

## 3. 交互规则

1. 落点：首次进入为「所有工作区」；之后保留上次位置（含 drill-in 的工作区），从标题栏按钮进入则定位当前工作区。`g a` / 面包屑返回 All。
2. 跨区注意力项：点击 → 选中所属工作区并展开该任务；运行项 → 选中工作区并打开执行会话。
3. 工作区卡片：整卡可点进入；`…` 菜单（后续）提供打开设置/复制路径。
4. 键盘：`g a` 返回所有工作区；`⌘K` 可在 All 下跨区列出任务/会话，执行时先定位工作区。
5. 空态：无工作区 → 说明 + 引导；工作区无任务 → 卡片显示 0，不制造假数据；工作区任务板读取失败 → 卡片标注「任务板无法读取」，不静默显示 0。
6. 设置只在工作区层出现；All 层不显示 ⚙（避免"在哪个工作区上改"的歧义）；设置页 `Esc` 先退出设置；有未保存修改时提示「放弃修改」后才退出（真正的离开拦截与草稿暂存列后续）。
7. All 层注意力覆盖：阻塞、可能卡住、执行结束待确认、高优先级、环境异常；**子会话未读只在工作区视图呈现**（跨区未读需要 Host `lastReplyAt` 与全局 seen 状态，列入后续）。

## 4. 验收

- 侧边栏常驻「中枢」，点击恢复上次位置（首次进入 All）；标题栏按钮进入并定位当前工作区；`g a`/面包屑回 All。
- All 首页一屏看到跨区注意力/运行/环境；点卡片或注意力项能正确 drill-in。
- 工作区视图面包屑可回 All；设置只作用于选中工作区。
- Host `hub.overview` 有测试；client-ui 测试断言全局面板 key 与 `sidebar.panellist`；harness 新增 All 暗/亮截图。
