# 工作区中枢 · 交互逻辑与 UI 重构方案

> 版本：v1（2026-10-22）  
> 参照实现：`client.js`（2232 行）· `lib/*.js`  
> 设计语言：DSH 宿主原生（`--dsw-alias-*` token），深色优先  
> 设计智识来源：OpenDesign（craft 规则 / design-systems / 评审 checklist），见 `02-opendesign-toolkit.md`  
> 原型：`docs/redesign/prototype/index.html`　截图：`docs/redesign/screens/`

---

## 0. 一句话结论

现在的中枢是「四个标签页 + 四张 CRUD 列表」：它把数据放全了，却没有回答工作区最常被问的问题——**现在什么在跑、什么卡住了、我该做什么**；任务、执行它的会话、环境状态在界面上互不相认，用户只能靠 session id 自己拼。

量化现状（审计实测）：面板打开时 **≈85 次请求/分**（5 条定时器：4s 面板、4s 服务器、8s 胶囊、5s 子会话目录、10s 工作区目录），55 个按钮、9 级自造字号；后端 25 个桥方法中 **5 个能力没有 UI 入口**；README 承诺的「子会话发送/中断/重开」在界面上不存在。

重构方向：**把中枢从「列表页」改造成「工作台（Console）」**——一个以「注意力队列 + 正在运行 + 环境」为首页、任务与执行者显式关联、全部操作就地完成、键盘可闭环的工作区驾驶舱。视觉上不再模仿 macOS/Apple（上一版探索的问题），而是回到 DSH 自己的设计语言：石墨表面、发丝线、单一主色、等宽元数据、紧凑而安静。

## 1. 现状判断（依据 `01-current-audit.md`）

三个结构性根因，不是视觉细节：

1. **信息架构按「数据类型」切，而不是按「用户意图」切。** 任务 / 会话 / 服务器 / 工作区 四个标签页是四张表。用户想知道"派发的任务跑完没有"，要在任务页看负责人 id，再去会话页找标题，再去子会话页看回复。**关系不可见 = 每次都要人脑 JOIN。**
2. **交互是「提交-等待-整页刷新」。** 每个写操作 `busy` 锁整页 → 成功后串行 `refresh()` 三个请求 → 所有列表重渲染。没有乐观更新、没有撤销、冲突只能弹一句通用错误；4 秒轮询每轮 3 个串行请求。对"点一下勾"这种动作，反馈链路太重。
3. **中枢是"要去的地方"，不是"会叫你的地方"。** 入口按钮不携带任何注意力信号（阻塞任务、失败的服务、子会话新回复），面板打开后固定显示 5 步新手引导；关闭即遗忘（筛选、展开、滚动全部丢失）。它没有任何"拉"用户回来的机制。

补充事实（详见审计）：任务卡逐条成卡、8px 间距，一屏只能放 6–7 条；`rev 3`、`session-5fe3` 这类实现细节直接暴露给用户；`window.confirm` 删除；`role="tab"` 没有方向键；服务器是条件出现的第四个 tab（不同工作区导航结构不同）；"工区"信息只读链与编辑器混排在同一页。

## 2. 设计目标与原则

**目标（按优先级）**

| # | 目标 | 可检验结果 |
|---|---|---|
| G1 | 3 秒内回答"工作区现在怎么样" | 首页首屏含：运行中的执行、待你处理项、环境状态 |
| G2 | 主路径少一步 | 派发 6 步 → 3 步；完成任务 1 步 + 可撤销；新建任务 1 步（Enter） |
| G3 | 任务与执行者可追踪 | 任务行始终显示执行者与最近活动；展开可见运行摘要与入口 |
| G4 | 不打断、不跳变 | 稳定分区更新；乐观更新；冲突就地解决；失败保留旧数据 |
| G5 | 键盘闭环 | 打开面板后可全程键盘完成：导航、筛选、创建、派发、完成、撤销 |
| G6 | 与宿主一体 | 只使用 DSH token 与组件语法；暗/亮主题自动成立；无第二品牌色 |

**设计原则**

1. **Attention first.** 首页先放"需要你处理"，再放"正在运行"，最后才是"环境/最近"。默认排序 = 紧急度 × 影响面，不是创建时间。
2. **一行一个对象，一行一个主动作。** 其它操作进 hover/focus 的次级位或 `⋯` 菜单；破坏性操作永不作为主按钮。
3. **关系显式化。** 任务 → 执行者（会话/子会话）→ 最近活动，三者永远同时可见，用标题不用 id。
4. **就地优先，浮层其次。** 改名、改状态、加备注、回消息都在原位；只有"派发""选择工作区""命令面板"用浮层/escalation。
5. **状态稳定、变化可追。** 分区骨架不动；新增/变更以淡入与行内高亮表达；任何写操作先本地生效，失败回滚并给可执行提示。
6. **只用宿主的语言。** 颜色、字体、圆角、焦点环全部来自 DSH token；不自造第二套视觉系统，不做拟物/玻璃/渐变。
7. **默认可访问。** 焦点可见、键盘可达、图标有名字、颜色不作唯一信号、`prefers-reduced-motion` 生效。

## 3. 核心对象模型（交互逻辑的地基）

```
Workspace ─┬─ WorkItem  任务：状态 / 优先级 / 归属（我｜会话｜无人）/ 详情 / 备注 / revision
           │     └─ Run  一次执行：sessionId + 类型（主会话｜子会话）+ 状态 + 开始/最近活动 + 摘要 + 未读
           ├─ Session  对话：主会话 / 子会话；running｜idle｜closed；parent；最新回复；未读
           ├─ Environment  开发服务器：ready｜running｜starting｜stopped｜external｜failed（+ 错误输出）
           └─ Contract  规则链（AGENTS.md 各层）/ 中枢上下文（CONTEXT.md）/ 技能
```

**关键改变**

- `Run` 成为一等概念：任务被认领/派发后，行上出现"执行中 · 3 分钟 · 最近活动"的运行条；运行结束但任务未完成 → 注意力项"执行已结束，待确认"。
- **归属只有三种**：我、某个会话、无人。UI 不再显示 `session-xxxx`，用会话标题（缺省"未命名会话"），正文里"我"用"你"。
- `revision` 从界面消失，转成后台并发控制；冲突在行内以"这条任务刚被更新"呈现。
- 环境不再是一个标签页，而是工作台状态的一部分（头部状态条 + 首页"环境"区 + 状态胶囊 popover）。
- 设置（规则/上下文/技能）从导航项降为面板头部 ⚙ 的次级视图：它们是低频、易错的配置，不该与高频操作平级。

**派生注意力规则（可解释、可关闭）**

| 信号 | 规则 | 主操作 |
|---|---|---|
| 阻塞 | `status=blocked` | 打开任务 / 标记解决 |
| 可能卡住 | `doing` 且执行者 `idle` 且 `lastActivityAt` > 30 分钟 | 打开会话 / 放回队列 |
| 执行结束待确认 | `doing` 且 Run 已 settle | 确认完成 / 重开执行 |
| 高优先级无人认领 | `priority=high` 且 `status=todo` | 我来做 / 派发 |
| 环境异常 | server `failed` 或启动超时 | 查看日志 / 重启 |
| 子会话未读 | 子会话最新回复晚于 `lastSeen` | 打开 / 回复 |

首页最多 5 条，按上表顺序 + 时间排序；底部"查看全部 → 任务（按注意力筛选）"。规则命中原因必须写在第二行，不做黑箱"智能排序"。

**状态语义表（所有视图唯一来源）**

| 状态 | 形状 | 颜色 | 文案 |
|---|---|---|---|
| 进行中 / running | 2px 圆环（进行中旋转） | business 蓝 | 进行中 / 运行中 |
| 已完成 / done | 勾选圆 | success 绿 | 已完成 |
| 待办 / idle | 空心圆 | 中性 | 待办 / 空闲 |
| 阻塞 / warn | 感叹三角 | warn 琥珀 | 阻塞 |
| 失败 / error | 实心点 + 错误行 | error 红 | 启动失败 / 已取消 |
| 已关闭 / closed | 斜杠圆 | 中性降饱和 | 已关闭 |

颜色只做辅助：任何状态点必须同时有形状或文案；看板列、任务行、会话行、子会话行、环境行只能引用此表，禁止局部另定义。

## 4. 信息架构

```
面板头部（sticky，56px）
  工作区图标 · 工作区名称（点击切换工作区） · 路径（点击复制）   [同步状态] [⌘K] [⚙]
状态条（sticky，36px）
  3 进行中 · 5 待办 · 1 阻塞 · 环境 1/1 · 更新于 3s      [环境 popover]
导航（40px，分段控件）
  概览 | 任务 12 | 对话 4

内容区（唯一滚动容器；内容最大宽 960px 居中，宽屏不拉满）
  概览：需要你处理 → 正在运行 → 环境
  任务：快速捕获 → 筛选/分组/视图 → 列表或看板
  对话：筛选 → 会话树（子会话缩进行内回复）
设置（由 ⚙ 进入的次级视图，带返回）：规则链 / 上下文 / 技能
浮层：命令面板（⌘K）· 派发 sheet · 环境 popover · 确认/撤销 toast
```

**为什么砍掉服务器 tab**：它是条件出现的第四个导航项，导致不同工作区导航结构不同（位置记忆失效），且它本质是"状态"而非"列表"。改为：状态条常驻 + 首页环境区就地启停 + 胶囊 popover 快捷操作。需要完整输出（日志/命令/目录）时，从环境区展开，而不是换页。

**工作区切换**：标题中的工作区名是切换器（最近 5 个工作区 + 全部工作区），切换即打开该工作区的面板；面板绑定工作区的事实要在标题上写明，避免入口推断导致"我在看哪个工作区"的困惑。中枢本身不常驻：点开会话会切走中枢（宿主 panel 模型），因此在会话页跳转前记录 returnPath，回到中枢时恢复上次视图；进一步的分栏/常驻属于二期。

**为什么保留顶部导航而不是左侧栏**：面板嵌在 DSH 内容区（约 900–1120px），左栏会挤压列表宽度；顶部 40px 分段控件与宿主标题栏节奏一致，视觉成本低、实现风险小。桌面宽度 ≥ 1200px 时可升级为左侧 168px 导航（预留，不在本期）。

## 5. 屏幕与组件规格

### 5.1 全局尺寸与排版

| 项 | 值 |
|---|---|
| 面板内边距 | 左右 24px；内容底部 32px |
| 头部 | 56px（标题 15/600；路径 11.5 mono / secondary；按钮 28px 高） |
| 状态条 | 36px，12px 文本；数字 `font-variant-numeric: tabular-nums` |
| 导航 | 40px 高；激活项 13/600 + 2px 下划线（`brand-primary`），非激活 13/400 secondary |
| 列表行 | 44px（紧凑）/ 56px（带第二行）；行间 0.5px `border-l1`（非整数屏用 1px 兜底）；**不再一行一卡** |
| 分组头 | 28px；11px / 600 / 0.04em 字距 / tertiary；右侧计数 |
| 控件 | 高 28px（次级）/ 32px（主）；圆角只用宿主档位：8px（控件/输入）、12px（容器/浮层）、16px（sheet/大卡）、4px（徽标/标签）。禁止 6/10/14px 自造档 |
| 字号阶梯 | 20 标题（设置页）· 15 面板标题 · 14 行标题/强调 · 13 正文 · 12 说明/元数据 · 11 徽标/计数（6 档，对齐宿主 10/11/12/13/14/20） |
| 行高 | 标题 1.4；正文/说明 1.7（中文必须，禁止拉丁 1.2–1.5）；元数据 1.5；等宽路径 1.5 |
| 图标 | 16px 线性 SVG，`currentColor`；不用 emoji |
| 焦点/选中 | 焦点：`outline: 2px solid var(--dsw-alias-state-business-primary)` + 2px offset，行内容器允许 `inset 2px`；绝不 `outline:none`。选中：business 蓝左 2px + 4% 底。导航「当前页」不用蓝色：字重 + 2px `label-primary` 下划线。一套语义，不混用 |
| 动效 | hover/按下 100ms、状态确认 160ms、浮层 200ms；曲线一律用宿主 `--ds-ease-in-out`（`cubic-bezier(.4,0,.2,1)`），不自造；`prefers-reduced-motion` 下 transform/scale/translate 全部归零 |

### 5.2 头部与状态条

- 标题：`工作区中枢` + 工作区名（如 `dsh-plugins`），下方 mono 路径，点击复制并 toast「已复制路径」。
- 右侧：同步状态文字（`更新于 3 秒前` / `同步中断 · 重试`）→ ⌘K 图标按钮（有 tooltip）→ ⚙ 设置。刷新不再是独立大按钮：点击同步状态即手动刷新。
- 状态条：`进行中 3 · 待办 5 · 阻塞 1 · 环境 1/1`，每项可点击跳转对应筛选；环境项点击开 popover（每台服务器的状态 + 启动/停止/打开）。
- 注意力未读：导航「概览」上带 2px 圆点 + 数字徽标（仅在有待处理项时出现），这是入口按钮"会叫你"的数据来源。

### 5.3 任务行（核心组件）

```
[状态控件]  标题（14/500，done 删除线 + 降饱和）                    [hover/focus 操作]
            高优先级 · 你 · 3 分钟前 · 执行中 2m · 最近活动一句           [⋯]
```

- 状态控件：todo 空心圆 / doing 进行中环 / blocked 琥珀感叹 / done 绿色勾 / cancelled 灰斜杠。**整行可点开**，控件本身单击即切换完成/重开（可撤销）。
- 第二行元数据仅在 56px 模式显示；紧凑模式 44px 时元数据右侧对齐。优先级只用 6px 点 + 文本（高=琥珀/红，普通/低不着色）。
- 执行者：会话标题可点，直接 `openSession`；hover 显示 tooltip 含最后一句活动。运行中加 160ms 脉冲点（`prefers-reduced-motion` 下静态）。
- hover/focus 操作：我来做 / 完成 / 派发 / ⋯；focus-within 时同样出现（键盘可达）。`⋯` 菜单：放回队列、编辑、复制链接、删除。
- 删除不弹 `confirm`：直接移除 + 底部 toast「已删除『标题』 · 撤销」6 秒；撤销失败则提示"任务已不存在"。
- 多选：`x` 或 hover 出现复选框；有选中时导航下方出现批量条：`已选 3 项  [我来做] [完成] [派发] [删除] [取消]`。批量逐条提交，部分失败逐条回滚并汇总。

### 5.4 概览（默认首页）

三个分区，顺序固定：

1. **需要你处理**（最多 5 条，行 56px）：左侧语义图标（阻塞/卡住/未读/环境），标题 + 原因第二行，右侧 1 个主操作 + `⋯`。
2. **正在运行**（行 56px）：脉冲点、任务标题、执行者、已运行时长、最近活动一行省略、`[打开] [中断]`。没有运行时整区折叠为一行「现在没有运行中的执行」+「查看对话」链接。
3. **环境**（紧凑卡片一行一台）：状态点 + 名称 + URL（mono，可点打开）+ `[启动]/[停止]`；启动中显示已用时长 + `[取消]`（异步 job，不再阻塞整页）；就绪后可自动打开（可选，默认记住上次选择）；失败行展开显示错误尾部 3 行 + `[查看日志]`（完整输出浮层）。状态必须互斥：启动中 / 已就绪 / 启动超时 / 已崩溃 / 外部运行 / 已停止，不得把"超时失败"继续显示成"启动中"。

空工作区：线性图标 + 一句话 + 快速捕获输入 + 3 个起始模板（如"梳理这个仓库的待办""修一个 bug""写一份 README"）——点击只填入输入框，不直接创建。

### 5.5 任务视图

- **快速捕获**：顶部常驻 40px 输入，占位「记一条任务，Enter 创建 · Tab 补充详情 · ⌘N 聚焦」。Enter 创建后输入框清空并保持聚焦，行插入列表顶部并高亮 600ms；Esc 失焦。Tab 展开详情/优先级/归属的展开区（不弹大表单）。
- **筛选**：分段 chips：全部 12 / 待办 5 / 进行中 3 / 阻塞 1 / 已完成 3（另可切「已取消」）；选中的筛选记住（按工作区持久化）。搜索在客户端过滤（≤200 条）；超过阈值再向 Host 增加 `tasks.list.search` 参数（列入 §9 依赖）。状态筛选复用 `tasks.list` 的 status/mine。
- **分组**：默认按**状态**分组（待办/进行中/阻塞/已完成），避免与概览的注意力队列重复；工具行顶部提供「需要你处理」pinned 快捷筛选（复用注意力规则），可切「优先级 / 不分组」；排序：优先级 > 更新时间；已完成默认折叠为一行（N 项 · 展开）。
- **视图切换**：列表 ⇄ 看板；看板四列（待办/进行中/阻塞/已完成），卡片三行，支持拖拽 + 键盘 `[` `]` 改状态（拖拽不是唯一路径）。
- **行展开**（点击标题或 `e`）：标题/详情/优先级可编辑（点击进入行内编辑，自动保存，显示"保存中/已保存"）、备注时间线（可追加）、运行条（执行者 + 状态 + 最近活动 + `[打开会话] [中断]`）、动作条（我来做/完成/派发/标为阻塞/取消/复制链接/删除）。
- **空状态**分两种：无任务（含捕获框 + 模板）、筛选无结果（"没有『阻塞』的任务 · 查看全部"）。
- **底部**：`更新于 3 秒前 · 自动刷新`；错误时变 `同步中断 · 已重试 2 次 · 点此重试 · 显示的是 2 分钟前的数据`，旧数据保留、置灰边缘不阻塞操作。

### 5.6 派发 sheet（多步任务的唯一浮层）

480px，居中，遮罩 `rgba(0,0,0,.4)`，焦点陷阱：

```

(•) 当前对话的子会话  挂在「整理工作区路径的展示规则」下
( ) 已有对话        选择…（最近 5 个，带运行状态）
```

- 1/2/3 选择目标，Enter 提交，Esc 关闭；提交后按钮进入 loading，成功 toast「已派发给〈会话标题〉 · 查看」并在任务行出现运行条。
- 目标会话下拉展示"会话标题 + 运行中/空闲 + 最近活动"，不再显示截断 id；`expectedRevision` 冲突时就地提示"任务已变化，已刷新，请再确认"。

### 5.7 对话视图

- 工具行：筛选（全部/运行中/空闲/有未读）+ 搜索；右侧 `[+] 新建子会话`（目标为当前选中会话）。
- 会话行 48px：状态点 + 标题（当前会话带"当前"徽标）+ 元数据（运行/空闲、最后活动、子会话数、未读徽标、关联任务数）+ `[打开] [⋯]`；点击行展开子会话。最后活动取最近一条 assistant/消息摘要（失败要显示原因，不只显示 idle）。
- 子会话行 40px：状态点 + 标题 + 最新回复两行截断（等宽引用块不抢视觉）+ 时间 + `[打开] [中断/关闭/重开]`；运行中展开行内输入「发消息…（⏎ 发送，⇧⏎ 换行）」。
- 关闭子会话：立即置灰 + toast「已关闭 · 重新打开」；不打断主对话。会话页提供"显示已关闭"开关（关闭项不再消失，可重开）。
- 无权限/无 live 会话：行内说明"需要先打开一个对话才能新建子会话" + `[打开当前对话]`，不显示只能失败的按钮。所有 disabled 按钮必须带一句原因（tooltip 或行内文案）。

### 5.8 设置（⚙）

- 形态：头部替换为 `← 工作区中枢` + `工作区设置`，内容 20px 标题 + 分组；不占用导航。
- **规则链**：按继承顺序列出（用户全局 → 项目根 → 当前目录），每行：路径（mono）、来源、字节数、是否可编辑；可编辑行点开即行内编辑器（保存中/已保存/未保存离开提示）。
- **上下文**：中枢托管的 `CONTEXT.md` 编辑器 + 生效说明（只注入同目录会话，下一轮生效）。
- **技能**：搜索 + 来源徽标 + 可调用面（模型/用户）；新建走右侧抽屉（name/description/body），校验 kebab-case，失败信息就地显示。
- 所有保存：autosave 1s debounce + 状态文案 + `⌘S` 立即保存；写入带文件 hash 的 compare-and-set（Host 依赖项，未就绪前此交互只做占位演示、不作验收），冲突时提示"文件已被其他会话修改"并给出"采用最新/覆盖/另存"三选一；离开有未保存改动时拦截一次。三个表单用各自动词（保存规则 / 保存上下文 / 创建技能），不共用"保存"。仅破坏性重置要确认。

### 5.9 环境（从状态条/首页进入，不是 tab）

- 行内动作：`启动` → 立即进入"启动中 · 已 3s"并可取消；就绪后变为"运行中 · 就绪"，URL 可点；`停止` 只结束中枢自己启动的进程，外部进程标注"外部运行"且不提供停止。
- 失败：红点 + 一句原因 + 尾 3 行输出 + `查看日志`（浮层显示完整尾部 64KB）+ `重启`。
- 未配置：显示"未声明服务器 · 自动识别已关闭"+ 指向 GUIDE 的配置说明，不显示空的 tab。

### 5.10 命令面板（⌘K）

560px，输入 + 分组结果（操作 / 任务 / 对话 / 工作区），模糊匹配，↑↓ 选择，↵ 执行，Esc 关闭。操作固定项：新建任务、新建子对话、启动服务器、打开设置、刷新数据、切换工作区。空输入展示最近 5 条任务与运行中对话。这是键盘用户的"任意门"，也是功能可发现性的兜底。

## 6. 交互逻辑规格（行为契约）

### 6.1 数据与刷新

- **一次快照**：客户端只调用 `hub.snapshot`（返回 context/board/sessions/servers + `generatedAt`），替代当前 `context + tasks.list + hub.sessions` 三次串行 + 5 条独立定时器（实测 ≈85 请求/分）；单定时器 4s + 单请求，服务器状态并入快照（健康探测降频到 10s 或仅在环境区可见时）。
- **合并而非替换**：按 id 合并，保留展开/选中/滚动/输入中的草稿；列表顺序稳定，不因更新时间重排（除非用户选了"按更新时间排序"）。
- **可见性**：页面隐藏暂停轮询；重新可见立即拉一次并显示"已刷新"。
- **退避**：连续失败 4s → 8s → 16s（上限 30s）；错误不阻塞内容，顶部显示 stale 提示。
- **手动刷新**：点同步状态文字，loading 200ms 内不闪烁（延迟显示 spinner）。

### 6.2 写操作与冲突

- 乐观更新：本地先改，立即反馈；请求失败 → 回滚该行 + 行内错误 + toast（附"重试"）。
- CAS 冲突：`409` 时拉取该任务最新版本，行内提示「已被〈会话〉更新」+ `[采用最新] [重试我的修改]`；不整页刷新。
- 批量操作：逐条提交，逐条回滚；汇总 toast「3 项完成 · 1 项失败（查看）」。
- 删除：软删除 6s 撤销窗口；`revision` 变化导致撤销失败时明确提示。
- 并发输入：派发/编辑按钮只锁自身行，不锁整页；服务器启动/停止是异步 job（进度 + 取消），期间其余行完全可用。

### 6.3 视图状态记忆（按工作区）

记住：最后导航、任务筛选/分组/视图、搜索词、对话筛选、滚动位置（列表锚定首项）、展开的任务 id、设置页最后分组、最近工作区。存储 `localStorage['dsh-hub:view:<workspaceId>']`；版本号 + 容错，脏数据回落默认。

### 6.4 键盘模型

| 键 | 作用域 | 行为 |
|---|---|---|
| `⌘K` / `Ctrl+K` | 面板 | 命令面板 |
| `n` / `⌘N` | 任务 | 聚焦快速捕获 |
| `/` | 任务/对话 | 聚焦搜索 |
| `j` `k` / `↑` `↓` | 列表 | 移动焦点（不滚动页面） |
| `↵` | 行 | 打开/展开 |
| `x` | 行 | 完成/重开（带撤销） |
| `e` | 行 | 行内编辑标题 |
| `d` | 行 | 派发 |
| `Esc` | 浮层/编辑 | 关闭/取消 |
| `g` `o` / `g` `t` / `g` `c` | 面板 | 概览/任务/对话 |

焦点环始终可见；浮层焦点陷阱 + 关闭后回到触发元素；toast `aria-live="polite"`，错误 `role="alert"`。

### 6.5 入口与注意力

- 标题栏入口按钮：保持「中枢」；有注意力项时右侧出现 2px 圆点 + 数字（`aria-label` 含数量），点击打开概览。标题栏按钮旁显示当前工作区名（短名），点击它打开工作区切换器，避免"不知道在看哪个工作区"。
- 服务器状态胶囊保留（紧凑版），点击打开环境 popover，而不是跳到某个 tab。
- 中枢不是常驻视图：从任务/会话点"打开"会切走中枢，因此记录 returnPath 并在面板内提供 `← 返回中枢` 的恢复语义（宿主布局允许时）；无法分栏时至少保证再点一次入口回到**上次视图**，而不是重置到任务页。
- 子会话入口收敛：侧边栏只保留"前导图标 + 有未读时的 badge"两种信号，都打开同一浮层；删除重复的 hover 卡片入口（或将其合并进浮层底部摘要），避免同一对象四个入口、四种行为。

### 6.6 错误与边界状态

| 状态 | 表现 |
|---|---|
| 首次加载 | 骨架屏（行高与真实行一致，不做整页 spinner），>2s 才出现 |
| 无工作区 | 空态说明 + "打开一个工作区" |
| 无会话/无任务 | 分区空态，保留捕获入口 |
| 数据过期 | 顶部细条 `同步中断 · 显示 2 分钟前的数据`，内容可读可操作 |
| 权限拒绝 | 行内说明 + 可执行入口（而非只报错） |
| 长标题/长路径 | 单行省略 + title 属性；展开后可读 |
| 大量任务 | 分组折叠 + 虚拟化阈值（>200 行） |
| 服务器失败 | 红点 + 尾 3 行错误 + 查看日志浮层 |
| 刷新中 | 仅同步文字变化，不闪骨架、不清空内容 |

## 7. 视觉系统

**方向名：Graphite Console（石墨工作台）**——DSH 原生 token 上的高密度工作台。参照 OpenDesign 的 `linear-app`（暗色优先、发丝线、密度、单一强调）、`raycast`（命令面板与键帽语法），**放弃** Apple/macOS 拟物、玻璃拟态、渐变、第二品牌色。

| 角色 | Token（暗/亮） | 用法 |
|---|---|---|
| 画布 | `--dsw-alias-bg-base`（#151517 / #fff） | 面板底 |
| 层级面 | `--dsw-alias-bg-layer-1/2/3` | 浮层、输入、hover 底 |
| 主文字 | `--dsw-alias-label-primary`（#f9fafb / #0f1115） | 标题 |
| 次要文字 | `--dsw-alias-label-secondary`（#cfd3d6 / #61666b） | 正文、说明 |
| 三级/元数据 | `--dsw-alias-label-tertiary` / `-caption` | 时间、计数、路径 |
| 发丝线 | `--dsw-alias-border-l1`（#ffffff0f / #0000000a） | 行分隔、卡片边 |
| 强边 | `--dsw-alias-border-l2/l3` | 输入、浮层边 |
| 主操作 | `--dsw-alias-button-primary-fill`（暗=近白，亮=近黑） | 唯一实心按钮 |
| 业务强调 | `--dsw-alias-state-business-primary`（#7aaaff / #4176e6） | 链接、焦点、进行中环 |
| 成功/警告/错误 | `--dsw-alias-state-success/warn/error-primary` | 仅状态点与语义文字 |
| 交互底 | `--dsw-alias-interactive-bg-hover` / `-active` | 行 hover / 按下 |

- **单一强调**：实心主按钮用宿主主色（暗色主题下是近白），业务蓝只用于链接/焦点/进行中；状态色仅出现在 6px 点、徽标文字与错误行；控制台场景**单屏彩色面积 <5%**（严于 OD 通用 5–10% 预算）。
- **层用亮度不用阴影**：暗色下通过 `bg-layer` 亮度阶 + 发丝线区分浮层；命令面板/菜单/派发 sheet 使用宿主 `--dsw-specific-menu`（自带 `--dsw-menu-backdrop-filter: blur(40px) saturate(150%)`），这是宿主原生材质，不算"玻璃拟态"；其它区域禁止 blur/渐变。
- **密度**：44px 行、8px 基线网格、24px 分区间距；不再一任务一卡（卡片的边框噪声是当前列表显乱的主因）。
- **图标**：16px 线性 SVG（自绘 6–8 个：概览、任务、对话、环境、派发、运行、更多、设置），`stroke-width:1.5`，不引第三方图标包以控制体积。
- **亮色**：不是反色；提高发丝线不透明度（`border-l2`），主按钮保持近黑，业务蓝加深一档，状态色使用 `*-secondary`。
- **无障碍**：正文对比 ≥4.5:1；单屏强调色 ≤2 处；状态色 ≤3 种；点击区 ≥28×28（行内次要按钮 24×24 + padding 命中扩展）；状态不止颜色（图标 + 文案）；焦点环 2px；`aria-live` 通知；`role=tablist` 支持方向键。

| 需求 | 归属 | 说明 |
|---|---|---|

| 服务器异步启动/进度/日志/取消 | Host | `start` 同步阻塞、`status` 不返回日志；需 job + logs 接口 |
| 文件保存冲突检测 | Host | 需返回 hash/mtime + If-Match |
| 面板内快捷键/⌘K | 纯前端（有边界） | 测试明确禁止注入 shortcuts 服务（`test/client-ui.test.mjs:112`）；只能在面板根节点挂 `keydown`，且仅当焦点在面板内时处理。若宿主已占用 ⌘K，降级为 `/` 或 `⌘⇧K`，并在设置里可关 |
| 软删除/撤销 | Host（优先）或前端补偿 | 推荐 Host 回收站端点；前端补偿（撤销=重新创建）会换 id，不可接受 |
| tab 级深链/恢复 | 前端 localStorage（本期） | layout 无路由；跨设备/刷新级深链属二期 |
| 工作区切换器 | 纯前端 | `hub.catalog` 已有列表，`layout.selectPanel` 可切 |
| 推送式更新 | Host（二期） | 本期保留 4s 单请求轮询 + 退避 |

### 兼容与回退

- 保留现有 API 与面板 key；`hub.snapshot` 缺失时客户端回退到三次调用。
- 服务器 tab 移除后，胶囊/环境 popover 仍需覆盖原有"启动/停止/打开"能力，不留功能洞。
- 一次性 feature flag（`localStorage`）可在旧/新外壳间切换一个开发周期。

## 11. 动效

- 行新增：`opacity 0→1 + translateY(2px)` 160ms；撤销删除反向。
- 展开/收起：高度用 grid-template-rows 0fr/1fr 过渡 160ms；不做弹跳。
- 浮层：scale .98 + opacity 200ms，关闭 120ms（退出快于进入）。
- 运行脉冲：2s 循环，仅透明度；reduced motion 静止。
- 禁止：滚动视差、hover 位移、布局抖动、连续自动动画。

## 13. 不做什么

- 不做独立 Web 应用或新路由（继续走 DSH 面板与槽位）。
- 不复制 Apple/macOS 视觉，不引入第二品牌色、渐变、玻璃拟态、emoji 图标。
- 不把拖拽看板作为唯一交互（必须保留键盘/菜单改状态）。
- 不新增全局快捷键（只在本面板内响应），不劫持宿主既有键位。
- 不引入第三方 UI/图标/图表依赖（控制体积与主题一致性）。
- 不在 P0 阶段改后端数据格式；字段只增不改，保证旧会话兼容。

## 附录 C · OpenDesign 的使用方式

1. `02-opendesign-toolkit.md` 的评审 checklist（craft：laws-of-ux / state-coverage / accessibility / animation / anti-ai-slop）用于原型自查与独立评审；
