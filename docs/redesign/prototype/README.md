# 工作区中枢 · 交互原型

单文件高保真原型：`index.html`（内联 CSS + 原生 JS，无构建、无网络、无外部字体/图标）。
DSH Graphite Console 语言，深色优先；亮色为同一 token 集。

## 路由（hash）
| 路由 | 屏幕 |
|---|---|
| `#/now` | 概览（暗）：需要你处理 / 正在运行 / 环境 |
| `#/now-light` | 概览（亮），明暗对照 |
| `#/tasks` | 任务列表（无选中） |
| `#/tasks-selected` | 任务列表 + 2 项选中与批量条 |
| `#/tasks-expanded` | 任务行展开：详情 / 备注 / 运行条 / 行内改标题 |
| `#/board` | 看板：待办 / 进行中 / 阻塞 / 已完成 |
| `#/dispatch` | 任务页 + 派发 sheet |
| `#/sessions` | 对话树（显示已关闭：关） |
| `#/sessions-closed` | 对话树（显示已关闭：开） |
| `#/settings` | 工作区设置（亮）：规则链 / 上下文 / 技能 |
| `#/states` | 兜底状态画廊 |
| `#/palette` | 概览 + ⌘K 命令面板 |

`#/settings`、`#/now-light` 强制亮色；其余跟随已保存偏好（默认暗色）。右上角主题切换（跟随系统/亮/暗）写入 `localStorage`。

## 键盘
`⌘K` 命令面板 · `n` 快速捕获 · `/` 搜索 · `j`/`k` 行焦点 · `↵` 展开 · `x` 完成 · `e` 编辑 · `d` 派发
`g o`/`g t`/`g c` 概览/任务/对话 · `Esc` 关闭 · `⌘S` 设置页保存
浮层：`↑`/`↓` 选择、`↵` 执行；派发 `1/2/3` 选目标、`↵` 提交；`Tab` 焦点陷阱。
图标按钮均有 `aria-label`；toast `aria-live="polite"`；错误 `role="alert"`。

## 模拟数据
工作区 `dsh-plugins`；12 个任务、4 个会话（含 1 个已关闭）、3 台服务器（就绪/启动中/启动超时）、4 层规则链、3 个技能；时间为相对时间。
写操作本地乐观模拟：完成/删除/批量可撤销 6 秒；服务器启停异步约 1.2s；派发只写回行内运行条并 toast，不创建真实会话。

## 已知限制
- 亮色主题可读性做了本地覆盖（元数据 `#61666b`、琥珀文字 `#b45309`、绿色图标 `#15803d`、控件边界 `#00000029`），待宿主 token 修复后移除。
- 多选批量、打开会话、新建技能等以 toast 反馈；无后端、无持久化（仅主题持久化）。
- 看板拖拽仅视觉提示，改状态用行操作/键盘；长内容单行省略 + `title`。
- 200 条压力数据在 `⋯ > 大量数据` 演示；<900px 行操作收进 `⋯`，看板单列堆叠。
